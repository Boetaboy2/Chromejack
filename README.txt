CHROMEJACK -> Windows .exe

1. Install Node.js (https://nodejs.org), LTS version.
2. Unzip this folder, open a Command Prompt inside it.
3. Run:   npm install
4. Test:  npm start
5. Build: npm run dist
   Your Chromejack.exe appears in the "dist" folder. It is a single portable file.

Needs internet the first time for the Google Fonts (falls back to system fonts offline).
